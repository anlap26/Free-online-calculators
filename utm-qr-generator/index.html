Open Semrush

Type a landing page address and the labels you want on the click. The builder uses URLSearchParams, so each value is encoded the way a query string should be encoded. A space, an ampersand, or a non-ASCII character will not break the pair it sits in. The keys are utm_source, utm_medium, utm_campaign, utm_term, and utm_content. Empty fields are omitted. A blank term does not become utm_term with an empty value, and it does not wipe a parameter that was already on the URL unless you typed the same key. The result is a normal address you can copy.

The address has to be a full URL. A bare path without a scheme is rejected, because the builder cannot know the host. Fix the address and run it again. The page does not look the URL up, does not check that it returns a page, and does not add a redirect. What you copy is what the parameters produced.

The QR code is drawn in the browser

The same link is drawn as a QR code on a canvas, on your device. The error correction level is H, the highest of the four usual levels. That spare capacity is why a small logo can sit in the centre. The logo, if you add one, is placed on a white pad so the pattern around it stays a clean quiet zone rather than a busy photograph. The drawing keeps the logo to a modest fraction of the code.

A logo that is too large will make the code unscannable. Error correction can rebuild a damaged or covered patch. It cannot rebuild a code whose middle has been replaced by a picture that eats the finders and the data. If a phone cannot read the result, shrink the logo or export the code with no logo at all. This page does not test a scan against a particular phone, and it does not promise that every camera will like a dark logo on a dark code. Print a sample before you send a run of posters.

A UTM labels the click. It does not create the campaign

The parameters do not start an ad, do not reserve a budget, and do not tell a shop what the click is worth. They only label the click so that whatever analytics you already run can group it later. If the landing page ignores query strings, the label is still on the request, but your report will not grow a campaign by magic. Naming source, medium, and campaign consistently matters more than inventing a new spelling each week. This form will not police the spelling.

What you do with the numbers later is the ROAS calculator. It does not read this QR. Open Semrush to see which queries and ads the campaign sat next to. Questions people ask

Are the utm values encoded?

Yes. They are set with URLSearchParams, so spaces and reserved characters are encoded. Empty fields are omitted.

Why is the QR at error correction H?

H leaves the most spare capacity of the usual levels, so a small logo can sit on a white pad in the centre.

Can the logo make the code fail?

Yes. A logo that covers too much of the pattern will make the code unscannable. Error correction cannot rebuild a code that has lost too much of itself.

Does a UTM create the campaign?

No. It only labels the click. The campaign, the budget, and the report already have to exist somewhere else.

Does this page store the links?

No. The address and the QR are built in the browser. Nothing is uploaded.
