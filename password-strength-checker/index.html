The checker reads the field in this browser and nowhere else. The password is not uploaded, and the arithmetic does not need a network. The estimate starts from the character classes that are actually present. Lower case contributes 26, upper case 26, digits 10, and any symbol or other character a further 32. Bits are the length times log2 of that sum. What you get is a model of brute force over the classes it saw.

What gets penalised

After the class count, the page penalises habits. A password on its short list of common ones, matched without caring about letter case, is capped at a very small estimate. A run of the same character, three or more in a row, cuts the estimate. A sequence cuts it too: abcd, 1234, or four keys along a keyboard row such as qwerty, including that row typed backwards. The penalties stack. A common password is limited first, a repeat cuts what remains, and a sequence cuts it again when the string has both. Password1 is on the common list once case is ignored. A long string can still be cut by 1234 or by qwerty sitting in the middle. Read the bits and the warning under them together.

The time on screen is a 50 percent brute-force estimate at the guess rate you pick: 10 billion a second, 10 thousand, or 1 thousand. It assumes the attacker tries that reduced space at random. It is not zxcvbn. It is not a breach check. The page never asks a leak collection whether this string has been seen. A reused password is already lost if one site leaked it, and this page cannot know that. The number can look large while the password is still a bad one to type into a second account. A fresh unique password comes from the password generator. A hash of the string is not a replacement password. A key you are about to use on the AES encryptor is worth a look here before you trust it. An alias from the address builder is a different string and says nothing about strength.

The field is on the screen

If you are on a shared computer, close the tab when you finish. The password sits in the field, in plain sight. Anyone who can see the display can read it. The script does not send the field anywhere. You can disconnect and the check still runs. The screen remains a copy until the tab is gone. Prefer to test a sample if you do not control the machine, rather than a password you still use on a bank or a mail account. Store unique passwords in a manager. Bitwarden and 1Password are the two named on this page. Plans change, and this page does not quote a price. The password manager guide is the comparison of what to check before you pick one.

Treat the whole result as a model. It tells you how large a class-based search looks after the obvious patterns are taxed. It does not tell you that a site you already signed up to has kept your password safe, and it does not score passphrases from the generator's word list the way that page counts words times 8 bits. If the generator dealt the words, trust that page's entropy. If you typed the string yourself, trust the warnings here.

Questions people ask

Does this send my password anywhere?

No. The script reads the field locally. You can disconnect the network and the check still runs. This site does not receive the password.

Is this zxcvbn or a search of leaked passwords?

Neither. It is an estimate from the character classes present, then a penalty for a common password, a repeat, or a sequence. It does not ask a breach list whether the string has leaked.

What does the time mean?

It is a 50 percent brute-force estimate at the guess rate you pick: 10 billion, 10 thousand, or 1 thousand guesses a second. It assumes a random walk over the reduced space, not a promise about a leak that already happened.

Why did a long password score badly?

A known common password is capped. Three or more of the same character, a run such as abcd or 1234, or a keyboard row such as qwerty, cuts the estimate. Those penalties can apply together.

I am on a shared computer. What should I do?

Close the tab when you finish. The password is on screen in the field. Anyone who can see the display can read it. The page does not store it, but the screen does until the tab is gone.
