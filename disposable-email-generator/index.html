Proton Mail

This page does not create a mailbox. It builds an alias string: two words from the list, a dot between them, four digits, an @ sign, and the domain you type. The digits are a random integer from 0000 to 9999, padded so the string always has four. example.com is the placeholder in the form, and example.com does not accept mail. Unless the domain is one whose inbox you already control, nobody can open this address. Pasting it into a signup is useful only when that signup will never need to write to you, or when you own the domain and catch the mail yourself. The words come from the same kind of list as the password generator, picked in the browser. Nothing is uploaded.

Plus-addresses

Plus-addressing writes the shape local+tag@domain. The page can build that from an address and a tag you supply. It takes the part of the local name before any plus you already had, then adds the tag you typed. It works only if the provider keeps the tag. Some deliver every plus-variant to the same inbox, some strip the tag and ignore it, and some reject the address. The tag this form accepts is letters, digits, dots, underscores, and hyphens, from 1 to 40 characters. The page cannot ask your provider which of those policies you are under. A tag that looks tidy in the box is still only a string until the provider agrees.

Shape, not a live inbox

The format checker tests shape, not whether the mailbox exists. A practical check is the one it runs: one @, a dot in the domain, and a local part that is present and at most 64 characters long. The whole address also has to fit in 254 characters, and each part of the domain has to look like a hostname label. A string can pass and still point nowhere. example.com can satisfy a shape check and still accepts no mail. The checker does not open a connection to a mail server to find out. Do not treat a passing note on this page as proof that a person, a company, or a throwaway host is listening.

When you need a real inbox

When a message has to arrive, use a real provider. Proton Mail is one such mailbox. Alias and hide-my-email style addresses, where a provider offers them, differ by plan, and plans change. This page does not switch those features on, and it does not keep a catalogue of what each plan includes this month. A new address still wants its own password from the password generator, and you can look at that password on the strength checker before you save it. The policy draft is a separate page, for a site that collects mail and needs to say so. The IP test does not create an inbox either. The password manager guide is about storing the password, not about receiving the message.

Questions people ask

Did this create an inbox I can open?

No. It built a string from two words, four digits, and the domain you typed. There is no mailbox behind it unless that domain is one you already control.

Can I receive mail at the example.com address?

No. example.com does not accept mail. It is a placeholder. Replace it only with a domain whose mailbox you control, or treat the string as a label.

What does the format check prove?

That the shape looks like an address: one @, a dot in the domain, and a local part that is present and not over 64 characters. It does not ask a server whether the mailbox exists.

Will plus-addressing always work?

Only if your provider keeps the tag. The page can write local+tag@domain. Some providers deliver those to the same inbox, some strip the tag, and some reject the address. The page cannot see which kind you have.

Does Proton hide my address for me?

Proton Mail is a real mailbox. Alias and hide-my-email style features, where a provider offers them, differ by plan, and plans change. This generator does not turn those features on.
