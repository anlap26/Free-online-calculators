Open Semrush

The generator writes a title element, a meta description, a canonical link when you give a URL, and the Open Graph tags people expect on a share: title, description, url, type, site name, and image. The Twitter card is summary_large_image, with the same title, description, and image, plus a site handle if you typed one. A small JSON-LD block of type WebPage carries the name, the description, and the URL when there is one. Empty optional fields are left out, so you do not get an Open Graph image tag with a blank address.

The page warns when the title is past about 60 characters and when the description is past about 160. Those numbers are display habits. Search results often cut a long title or a long description, and social cards do something similar, but there is no hard rule that a longer string is invalid HTML or that a shorter string will rank. The warning is a nudge to look at the line, not a pass or fail grade. Count is by code points, the same way the text tool counts characters.

Quotes are escaped so the tag does not break

HTML is escaped before it is placed in an attribute or in the title element. A quote, an ampersand, or a less-than sign in your title becomes the matching character reference. That is why a title with a quotation mark cannot close the content attribute early and spill the rest of the tag. The JSON-LD is produced by a JSON serializer, so quotes inside the description are escaped there too. You can copy the block and paste it into the head of a page. The generator does not upload it, and it does not edit your host.

One H1 on the page itself is a separate question. This tool does not invent the H1, and it does not check the H1 you already published. The title element and the visible H1 can match, or they can differ, and the form has no opinion. If you want a word count of the body that sits under that H1, use the text analyzer. It will not write the H1 either.

What you still have to do by hand

Pasting the tags into a real page is your step. A preview on this site is not the head of your site. The canonical URL should be the URL you want counted as the original, not a copy with tracking parameters. The Open Graph image should be an address that a crawler can fetch, not a file that only exists on your laptop. The type field defaults to website if you leave the usual value. Change it only when you mean a different Open Graph type.

The block will not tell you which title people search for. Open Semrush and look that up before you freeze the wording. This page does not send your title there. Questions people ask

Will a title over 60 characters be rejected?

No. The warning means search results often cut long titles. It is a display habit, not a rule that the HTML is invalid.

What happens if the title contains a quote?

The quote is escaped before it is placed in the attribute, so it cannot close the attribute early.

Does this write the H1?

No. It writes head tags. The single H1 on the page is a separate decision, and the form does not invent one.

Which tags are included?

Title, meta description, canonical, Open Graph title, description, url, type, site name, and image, a Twitter card, and a small WebPage JSON-LD block.

Does the page publish the tags for me?

No. You copy them and paste them into the head of a real page. Nothing is uploaded.
