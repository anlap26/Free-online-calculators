Free online calculators

Thirty-five calculators and small utilities for money, privacy, relocation, and the web. Each one runs in your browser. English is the main language, and every page has a Russian version.

Every calculator runs in your browser. Results are arithmetic, not financial, tax, legal, immigration, or insurance advice. Check a current offer before you act. Affiliate links are marked.

The point of this site is a fast answer to a specific question: what a balance becomes if you add a fixed sum each month, what a stop-loss implies for position size, whether a bank's rate hid a spread, how many Schengen days are left, what a freelance hour has to earn, what an API call costs at the prices you type in. The tools are grouped so a person comparing exchanges, a person moving country, and a person shipping a page can each start in the right cluster and then follow the related links.

Nothing you type into a finance form, a password box, or the encryptor is sent to a server of ours. There is no account. The IP test is the exception, and that page says so: it asks public lookup services for the address they see. Photos you strip and images you compress are handled with the browser's own file tools.

Some pages link to brokers, exchanges, wallets, VPNs, insurers, eSIM sellers, and hosts. Those links are affiliate links. They are marked, and the whole list lives in one file so a partner URL can be replaced without editing the pages. The calculator does not change its arithmetic to favour a partner. Prices and plan rules change, so the articles describe how to compare rather than quoting a tariff that would be stale next month.

If you want the same tool in Russian, use the RU switch in the header. The URL keeps the same slug under /ru/, and the language tags point both ways.

Questions people ask

Are these calculators free?

Yes. There is no account and no payment. The site is funded, if a partner pays, by labelled affiliate links.

Do you store what I type?

No. Calculations run on your device. The IP test calls public lookup services, which see the address they are asked about. This site does not receive that request.

Is the result financial or legal advice?

No. It is arithmetic from the numbers you entered. Tax, visas, insurance, and investing depend on facts this form does not have.

Can I use the Russian pages?

Yes. Every calculator and every guide exists in Russian under /ru/, with matching titles and a language switch.
