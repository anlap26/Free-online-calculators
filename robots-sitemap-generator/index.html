Open Semrush

The robots text starts with a user-agent line for every crawler, written as User-agent with an asterisk. Each path you list under Allow becomes an Allow line. Each path under Disallow becomes a Disallow line. A Sitemap line points at the map. If you listed page URLs and a site address, the robots file points at a sitemap.xml on that host. The XML file is a urlset. Each address you typed becomes a loc element. The generator escapes XML, so an ampersand in a URL cannot break the document. Blank lines are dropped.

A disallow of /admin asks cooperating crawlers not to fetch URLs that begin with that path. It does not hide a URL that is linked from somewhere else. A person with the address can still open it. A crawler that ignores robots.txt can still fetch it. If the page must stay private, you need access control on the server, not a line in a text file. Allow is the matching exception: a more specific allow can sit beside a broader disallow. The order and the way a given crawler reads the two lines are defined by that crawler. This page writes the lines you asked for. It does not simulate Google, Bing, or anyone else.

A sitemap is a list, not a boost

A sitemap is a list of canonical URLs you would like crawled. It is not a ranking boost by itself. Listing a URL does not make it deserve a query, and leaving a URL out does not erase a page that is linked. Put the canonical address in the list, not a copy with tracking parameters and not a duplicate you hope to demote. The file will not check that the URL returns a page, that the canonical tag agrees, or that the page is the one you meant. Those checks happen on the host, after you upload.

You must put both files on the real host. A preview here is not robots.txt at the root of your domain, and it is not /sitemap.xml. Save the text, upload it to the place your server actually serves, and request the URL in a browser to see that the file is the one you wrote. This site does not deploy it for you.

Google Search Console is the place to submit a sitemap for a site you have verified there. This page does not submit it, does not sign you in, and does not know whether the property is verified. Other engines have their own submission pages. Mentioning Search Console is a pointer to the usual door, not a claim that we opened it. After a submission, what gets crawled is still the engine's decision.

Questions people ask

Does Disallow: /admin hide the page?

No. It asks cooperating crawlers not to fetch that path. A linked URL can still be requested, and a crawler that ignores robots.txt can still fetch it.

Does a sitemap raise rankings?

No. It is a list of canonical URLs you would like crawled. The list itself is not a ranking boost.

Are special characters in URLs safe in the XML?

The generator escapes XML, so an ampersand does not break the document. You still have to put the file on the host.

Will this page submit the sitemap to Google?

No. Google Search Console is where a verified owner submits a sitemap. This generator only writes the text.

Where do the files have to live?

On the real host, where the server will return them. A preview on this site is not your robots.txt and not your sitemap.xml.
