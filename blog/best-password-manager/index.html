1Password, Bitwarden, and Proton Pass

Why a unique password matters, what a manager actually stores, and how to tell an open-source client from a polished app and from a mail suite.

A password manager stores a different secret for each account and fills it when you are on the matching site. The point of a unique password is mechanical. If one shop leaks its database, that leak opens only the shop. The mail account, the bank, and the hosting panel stay shut, because they never shared the secret. Reuse turns one breach into a tour of your life. People reuse because memory is small. A manager is a way to stop using memory for anything except one master secret, and, on some products, a second printed key that is not the same thing.

What the manager actually holds is a vault: site passwords, and often notes, card numbers, and one-time codes. Check the current feature list before you assume a given type of item exists. The vault is encrypted. The company may store the ciphertext so your phone and your laptop can meet. Holding ciphertext is not the same as holding a list of readable passwords, and it is also not a reason to call the product beyond reach. A phishing page, a malware infection on an unlocked laptop, and a master password you also used on a forum are ordinary failures. None of them requires a dramatic break of the cipher.

How to compare without a lab

You can compare 1Password, Bitwarden, and Proton Pass without hiring a lab. Read the security description the company publishes, the price page for the plan you would actually buy, and the help page for export and recovery. Write down three answers. Can you take the data out in a format you could import elsewhere. What happens if you forget the master password. Who else can be invited, and is there a waiting period before they get in. If a review gives a score, ignore the score and open the document it claims to summarise. Plans and prices change. Check the current page rather than a screenshot from last spring.

1Password

1Password is a polished independent app. The reason people pay for it is the fit and finish: the way it behaves on a phone and a laptop, the way sharing is explained, the way an emergency kit is printed. It is not the same kind of claim as open source. You are trusting the vendor and the audits they publish, which you should read for date and scope, rather than reading every line of the client yourself.

The secret key, in the design 1Password has described for years, is an extra high-entropy key that sits beside the account password. It is meant to stay off the company's servers. You keep a copy, often as a printed kit, because a new device may ask for it. Treat that description as a reason to read the current white paper, not as a promise that every screen in today's app uses the same words. Store the kit somewhere that is not the same note as the master password, and not a photo in a cloud album. Anyone who has both can open the vault. The company cannot read the vault back to you if you lose both. That is the trade.

Bitwarden

Bitwarden is open source. The clients are published so a reader can compare the product with the code, and so researchers can look without asking permission. Open source does not mean the hosted service is a co-operative you operate. A Bitwarden account on their cloud is still their service: their uptime, their account recovery rules, their jurisdiction. Read those pages. Self-hosting has been offered as a separate path. Confirm whether it still exists and what you would be taking on. Running a server is a different job from using a hosted vault, and a neglected server is not a privacy feature.

Bitwarden is the option for someone who wants the code in public and a product that can start on a free tier. Confirm what the free tier includes this month: the number of users, the items it syncs, and whether a hardware security key or a family seat is reserved for a paid plan. Do not inherit those limits from a blog post. The interface is plainer than 1Password's. For many people that is a virtue. For others it is the reason they pay someone else. Neither reaction is a measurement of the cipher.

Proton Pass

Proton Pass is the password manager in a suite that also does mail. Proton is a Swiss company, and Proton has published source for a number of its apps. Check that the Pass client you install matches a repository they currently publish, rather than assuming every build is something you can recompile from a blog. The practical reason to choose Pass is the suite. If your mail already lives there, a vault in the same account is one less vendor. The matching cost is concentration. The company that can lock the mailbox can lock the vault. Name that before you merge them.

A free offering for Pass has existed alongside paid plans that add features. Confirm the current limits. Aliases, sharing, and two-factor storage are the kind of items that move between tiers. If you came from Proton VPN, the same account habit applies, and the VPN comparison is a separate decision. A mail suite does not hide your IP. A VPN does not store your passwords. People who want both still have two jobs.

The extension, the PIN, and someone else's computer

A manager earns its place when it fills a secret on the domain it was saved for. Pasting into whatever box asked throws that check away. A phone PIN opens the local copy. It is not a second master password, and the vendor cannot turn it back into the vault. On a shared computer, a guest profile matters more than the brand. Read the current help for how to drop a session if the laptop is lost. Breach watching, where a plan includes it, compares your material with dumps already published. It is a notice. A letter that a password showed up is a reason to change that password, after you read what was compared.

Sharing, travel, and emergency access

Family and travel features should be read off the current plan, not memorised. Some products let a household share a subset of items without handing over the whole vault. Some have offered a way to pull sensitive vaults off a device before a border crossing. The name, the steps, and whether the feature is included in your tier all change. Confirm them on the help page you trust this month. A border question is a legal situation. This article does not tell you what to say. It tells you to learn, before you fly, whether the app can remove items and how you put them back.

Emergency access, described generally, is a designated person and a delay. You name someone. They request access. A waiting period gives you time to refuse if the request is a mistake or a theft. Other products skip the social feature and give you a printable kit instead. Read which model you are buying. A waiting period of unknown length is not a plan. Write down where the kit is, who else knows, and what happens to the vault if you are simply unavailable. Do not put the only copy of the recovery material in the vault it is meant to recover.

Entropy, the local checker, and two tools that are not a vault

Entropy is a count of how large the guessing space is. A longer password drawn from a larger alphabet has more of it. The password generator on this site draws from the browser's cryptographic random source and shows that count for the length and the character sets you picked, or for a passphrase drawn from a word list. The number is a model of brute force. It says nothing about a password that has already leaked, and nothing about a password you reused. Generate a unique one per site. Let the manager remember it. Remember the master password, and write the extra key down in the physical way the vendor describes.

The strength checker stays on the device. It estimates entropy and looks for common passwords, repeats, and sequences. It does not upload the field. Disconnect the network and it still runs. Treat a warning as a reason to generate a new secret, not as a certificate. The hash tool is a different job: a one-way digest of text you type, useful for a checksum, useless as a vault. Hashing a password and storing the hash in a note does not give you autofill, sharing, or a safe place to change one site without touching the others. The AES encryptor locks a note locally with a password. There is no sync and no recovery email. Lose the password and the note is gone. That is a good way to understand encryption. It is a poor substitute for a manager if you have a hundred logins and two phones.

Who it fits

1Password fits someone who will pay for a finished independent app and who will actually store the secret key apart from the master password. It is a weak fit if reading the client source is a requirement. Bitwarden fits someone who wants open-source clients, who may want to confirm a self-hosted path, and who is willing to read which features sit on the free tier this month. It is a weak fit if you want the vendor to make every decision about polish and you will not look at the security page. Proton Pass fits someone already inside that mail suite who accepts the concentration and has checked the current Pass limits. It is a weak fit as a first vault for a person who has no other reason to hold a Proton account.

This site did not pentest the three products, did not time their sync, did not count support replies, and did not review a breach-history timeline. It did not test autofill on every browser. A feature that fails on one obscure browser is something you can test in an afternoon with your own devices, which is a better test than a paragraph. Audits, where a company publishes them, should be read for scope and date. This page does not turn those PDFs into a winner. Prices were not copied, because they move. A commission on an affiliate link does not change the export test or the recovery test.

Limits

No manager here is unhackable, and this page will not say that about any product. A vault reduces the damage of reuse. It does not stop you from approving a prompt you did not mean, pasting a password into a look-alike site, or leaving a laptop unlocked. Check the current plan for price, family seats, travel behaviour, and emergency access before you rely on a memory of those features. Export a copy when the vendor's current instructions say how, and store that copy with the same care as the master password. The calculators help you make and judge a secret. They are not the vault.

Questions people ask

Will a password manager stop my accounts being taken over?

It stops the particular failure where one leaked database opens every site that shared a password. It does not stop a phishing page you choose to trust, malware on an unlocked laptop, or a master password you also used on a forum. The vault is encrypted. That is not the same word as unhackable, and this site will not use that word. Keep the master password and any extra key apart from each other, and store any exported copy the same way.

What is 1Password's secret key?

In the design 1Password has described, the secret key is an extra high-entropy key beside the account password. It is meant to stay off the company's servers, and a new device may ask for it. Print or otherwise keep a copy that is not the same note as the master password and not a photo in a shared album. Anyone with both secrets can open the vault. If you lose both, the company cannot read the vault back to you. That is the trade you are accepting.

Is Bitwarden safe because it is open source?

Bitwarden is open source, so the clients can be read and compared with the product. That is a real advantage and not a complete proof. A cloud account is still their service: their uptime, their recovery rules, their jurisdiction. Self-hosting has been offered as a separate path. Confirm whether it still exists and whether you are prepared to run it. A neglected server is not a privacy feature. Read which items the current free tier syncs before you assume a family seat or a hardware key is included.

Should I use Proton Pass if I already use Proton Mail?

One account is convenient, and it is also one company that can lock both the mailbox and the vault. Name that concentration before you merge them. Check that the Pass client you install matches a repository Proton currently publishes, and check which features sit on the free tier this month. Aliases, sharing, and stored one-time codes move between plans. A mail suite does not hide your IP. If you also want a tunnel, that is a separate product and a separate decision.

What is emergency access in general?

Emergency access usually means a person you name and a waiting period before they can open the vault. The pause gives you time to refuse a request that is a mistake or a theft. Some products skip that and give you a printable kit instead. Read which model your plan actually sells, and write down the waiting period rather than guessing it. Do not store the only recovery kit inside the vault it is supposed to open. Confirm family and travel features on the current help page before a trip.
