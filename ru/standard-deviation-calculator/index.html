Калькулятор стандартного отклонения

Среднее и оба стандартных отклонения введённых чисел. Сумма квадратов отклонений видна в дисперсии.

Дисперсия совокупности делит на количество. Дисперсия выборки делит на количество минус один.

Введите числа через пробел, запятую или с новой строки. Количество — сколько чисел прочитано. Сумма — их итог. Среднее — сумма, делённая на количество. Отклонение — число минус среднее. Сумма квадратов отклонений общая для обеих дисперсий. Дисперсия совокупности делит эту сумму на количество. Стандартное отклонение совокупности — квадратный корень. Дисперсия выборки делит на количество минус один и показывается, только когда чисел хотя бы два. Стандартное отклонение выборки — корень из неё. У одного числа стандартное отклонение совокупности равно нулю, а строки выборки нет: знаменатель выборки был бы нулём, а это не дисперсия.

Набор 2, 4, 4, 4, 5, 5, 7, 9 — проверка. Чисел 8. Сумма 40. Среднее 5. Квадраты отклонений — 9, 1, 1, 1, 0, 0, 4 и 16, в сумме 32. Дисперсия совокупности — 32/8 = 4, стандартное отклонение совокупности — 2. Дисперсия выборки — 32/7. Страница показывает эти значения. Минимум и максимум — самое маленькое и самое большое число, здесь 2 и 9. Пустой список отвергается. Жетон, который не число, отвергается, а не пропускается, чтобы случайное слово тихо не уменьшило количество.

Какую строку читать

Строку совокупности берут, когда числа — весь интересующий набор: все оценки класса, который вы описываете, все измерения, которые у вас есть и которые вы не собираетесь обобщать. Строку выборки берут, когда числа — выборка, а дисперсия должна оценить большую совокупность. Делитель выборки — поправка Бесселя. Она не делает оценку стандартного отклонения несмещённой. Это обычный делитель для дисперсии. Страница печатает обе строки, чтобы выбор оставался на странице, а не в спрятанном умолчании. Округление показа — не изменение деления. Очень длинные списки ограничены тем, что можно вставить, а не скрытым потолком формулы.

Вопрос про процент двух чисел — другая страница. Дробь — другая страница. Эта не скажет изменение в процентах и не сократит отношение. Если числа — стороны треугольника, страница треугольника проверяет неравенство и считает площадь. Среднее трёх сторон — не площадь.

Чем два делителя не являются

  • Строка выборки не «точнее» для полного набора.
  • Строка совокупности не ошибочна для выборки. Она отвечает на другой вопрос.
  • Ни одна строка не является доверительным интервалом.

Проверка набора из восьми чисел занимает минуту на бумаге. Сумма квадратов отклонений от пятёрки равна 32. Деление на 8 даёт дисперсию совокупности 4 и корень 2. Деление на 7 даёт дисперсию выборки. Если страница показывает другой корень, она поделила не на то число.

Процент по двум числам — на калькуляторе процентов. Целые отношения — на калькуляторе дробей. Три длины — на калькуляторе треугольника.

Частые вопросы

Какое стандартное отклонение у 2, 4, 4, 4, 5, 5, 7, 9?

Среднее равно 5. Сумма квадратов отклонений равна 32. Стандартное отклонение совокупности равно 2, потому что 32/8 = 4, а корень из 4 равен 2. Дисперсия выборки равна 32/7.

Почему стандартных отклонений два?

Дисперсия совокупности делит на количество. Дисперсия выборки делит на количество минус один. Строку выборки берут для выборки из большего набора, строку совокупности — когда список и есть весь набор.

Что будет с одним числом?

Среднее равно этому числу, стандартное отклонение совокупности равно нулю. Строка выборки скрыта, потому что делитель выборки был бы нулём.

Пустые строки игнорируются?

Разделители игнорируются. Жетон, который не число, — это ошибка, а не пропущенный элемент.
