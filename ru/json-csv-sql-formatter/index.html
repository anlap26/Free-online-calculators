Форматирование JSON, CSV и SQL

JSON разбирается и печатается с отступом. CSV оставляет запятую в кавычках внутри ячейки. SQL режется перед коротким списком слов и полным разбором не является.

Цены и ставки вводите вы. Тарифы продавцов меняются. Страница не замеряет ваш живой сайт.

Выберите JSON, CSV или SQL. Текст остаётся в браузере. Ничего не загружается и ничего не выполняется. Результат нужен, чтобы его скопировать. База, API или таблица на вашей машине не изменятся, пока вы сами куда-нибудь текст не вставите.

JSON сначала разбирается, потом печатается

JSON проходит через JSON.parse, затем через JSON.stringify с тем отступом, который вы задали. Отступ — небольшое целое число пробелов. Если число вне диапазона, который принимает скрипт, остаётся два пробела. Ключи выходят в том порядке, который дал разбор, а для обычного объекта это порядок в тексте. Форматировщик не сортирует ключи, чтобы два файла стали похожи, и не выбрасывает ключ, о котором вы не просили.

Если текст — не JSON, сообщение об ошибке принадлежит самому движку. Страница не переписывает его в более мягкую догадку. Висячая запятая, строка в одинарных кавычках или комментарий для JSON неверны, и движок скажет об этом своими словами. Поправьте текст и запустите снова. Комментарии скрипт молча не вырезает.

CSV оставляет запятую в кавычках в одной ячейке

Читатель CSV идёт по тексту. Запятая вне кавычек начинает новую ячейку. Перевод строки вне кавычек начинает новую строку таблицы. Кавычка открывает ячейку в кавычках, а удвоенная кавычка внутри этой ячейки — один символ кавычки, а не конец ячейки. Строка, где Doe, Ann стоит в кавычках, остаётся одной ячейкой, хотя между Doe и Ann есть запятая. Голая запятая без кавычек — настоящий разделитель. Строка, которая так и не закрыла кавычку, — ошибка, а не догадка. Печать снова берёт ячейку в кавычки только если в ней есть запятая, кавычка или перевод строки.

SQL — причёсывание, а не полный разбор

Шаг SQL проверяет, что кавычки и скобки сходятся, затем переносит строку перед фиксированным списком слов и пишет эти слова заглавными. Переносы включают SELECT, FROM, WHERE, AND, OR, JOIN, GROUP BY и ORDER BY, а рядом ещё HAVING, LIMIT и INSERT INTO. Слова внутри строки в кавычках не трогаются, потому что проверка баланса следит за кавычкой. Комментарий, который начинается с двух дефисов, пропускается, пока считаются скобки.

Это не полный разбор SQL. Неверную колонку, пропавшую таблицу или возможность диалекта, о которой шаг не слышал, он не поймает. Сходящиеся кавычки и сходящиеся скобки — единственная структурная проверка. Оператор может быть аккуратно разбит и всё равно оказаться неверным в момент запуска. Удачное форматирование — не разрешение выполнить оператор на боевых данных.

Причёсывание — ещё и не хостинг. Cloudways — хост, который может пригодиться, когда запрос правда должен где-то выполниться. Страница счёт не открывает, сервер не мерит и не знает, каким движком вы пользуетесь. Если рядом с запросом есть страница, которую вы собираетесь опубликовать, отдельный шаг для шапки — генератор мета-тегов. Хеш строки, когда он нужен, считается в инструменте хешей, тоже локально.

  • Ошибка JSON — это ошибка разбора движка, как есть.
  • Запятая в кавычках остаётся в одной ячейке CSV. Удвоенная кавычка — одна кавычка.
  • SQL пишется заглавными и режется по короткому списку слов. Плохая колонка всё равно проходит.
  • Ничего не загружается и ничего не выполняется.

Частые вопросы

Как выглядит ошибка JSON?

Это собственная ошибка разбора движка из JSON.parse. Страница не подменяет её догадкой.

Запятая в кавычках разбивает ячейку CSV?

Нет. Поле вроде Doe, Ann внутри кавычек остаётся одной ячейкой. Удвоенная кавычка внутри поля — один символ кавычки.

Форматировщик SQL поймает неверную колонку?

Нет. Он проверяет, что кавычки и скобки сходятся, затем переносит строку и пишет заглавными список слов. Это не полный разбор.

Перед какими словами SQL начинается новая строка?

Перед SELECT, FROM, WHERE, AND, OR, JOIN, GROUP BY и ORDER BY, а также перед соседними вроде HAVING и LIMIT.

Текст загружается или выполняется?

Ни то ни другое. Форматирование идёт в браузере. База оператор не видит.
