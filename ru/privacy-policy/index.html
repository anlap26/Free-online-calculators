Политика конфиденциальности

Эта политика описывает сайт «Бесплатные онлайн-калькуляторы» по адресу https://anlap26.github.io/Free-online-calculators/, издатель — Анна. Это описание того, как устроен этот сайт. Это не шаблон для вашего бизнеса. Если политика нужна другому сайту, соберите черновик в генераторе и дайте его прочитать тому, кто знает ваши факты.

Что сайт хранит

Сайт — набор файлов. Аккаунта, формы рассылки и базы посетителей нет. Числа, пароли, заметки и фото в калькуляторе остаются на странице. Проверка стойкости, генератор паролей, шифрование AES, снятие EXIF и сжатие картинок не отправляют эти данные нам. Аналитическую cookie мы не ставим и рекламную сеть на этих страницах не запускаем.

Проверка IP

Страница проверки IP и WebRTC устроена иначе. Когда вы нажимаете кнопку, браузер спрашивает у api.ipify.org адрес, у ipwho.is — грубое место и название сети, и открывает WebRTC-соединение с публичным STUN-сервером Google, чтобы собрать адреса кандидатов. Эти организации видят обычный запрос браузера, включая IP. Копию нам не присылают. Если кнопку не нажимать, этих вызовов нет.

Партнёрские ссылки

Некоторые ссылки уводят с сайта к партнёру. Партнёр может понять, что визит пришёл по партнёрской ссылке, и поставить свою cookie уже у себя. Это описано на странице раскрытия партнёрских ссылок. Данные вашего счёта у партнёра мы не получаем.

GitHub Pages и репозиторий

Файлы отдаёт GitHub Pages. GitHub обрабатывает запрос, которым приходит файл, по своим правилам. Исходный код лежит в публичном репозитории. Не присылайте секреты в issue.
