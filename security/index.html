Privacy and security tools

Generators and checks that keep passwords, photos, and private notes on the device, plus one IP test that says which outside service it calls.

The password generator draws from the browser's cryptographic random source. Entropy is the length times the log of the alphabet size, or the word count times the log of the word list. The strength checker uses a smaller estimate and looks for common passwords, repeats, and sequences. It does not upload the password. Treat both numbers as a model of brute force, not as a promise about a leak that has already happened.

The IP page asks ipify and ipwho.is what address they see, and it compares that with addresses gathered from a WebRTC connection to a public STUN server. A page cannot see your DNS resolver. The page says that, instead of pretending to run a DNS test it cannot run. EXIF removal parses a JPEG in the browser and can drop the metadata segments, or you can re-encode through a canvas. AES uses AES-GCM and PBKDF2. If the password is lost, the text is gone. There is no recovery email, because nothing was stored.

The guides compare three VPNs and three password managers in the same spirit: what each product is for, what to verify on the current plan, and what this site did not measure. A VPN does not fix a password you reuse. A password manager does not hide your IP.

Questions people ask

Does the password checker send my password anywhere?

No. The script reads the field locally. You can disconnect and the check still runs.

Will the IP test show my DNS server?

No. A normal web page cannot see that. It can show your public IP and any extra address WebRTC reveals.

Can you decrypt a note if I forget the password?

No. The key never leaves your browser, and we do not keep a copy.
