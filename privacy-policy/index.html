Privacy policy

This policy describes the site Free Online Calculators, published at https://anlap26.github.io/Free-online-calculators/ by Anna. It is a description of how the site is built. It is not a template for your own business. If you need a policy for a different site, use the policy draft generator and then have it read by someone who knows your facts.

What the site stores

The site is a set of files. There is no account, no newsletter form, and no database of visitors. Numbers, passwords, notes, and photos you use in a calculator stay in the page. The password strength check, the password generator, AES encryption, EXIF removal, and image compression do not send those inputs to us. We do not set an analytics cookie and we do not run an advertising network on these pages.

The IP test

The page My IP and WebRTC test is different. When you press the button, your browser asks api.ipify.org for an IP address, asks ipwho.is for a coarse place and network name, and opens a WebRTC connection that uses Google's public STUN server to gather candidate addresses. Those organisations see the request a browser normally sends, including the IP. We do not receive a copy. If you do not press the button, those calls are not made.

Affiliate links

Some links leave this site for a partner. The partner can tell that the visit came from an affiliate link and may set its own cookies on its own site. That is described on the affiliate disclosure. We do not receive your account details at the partner.

GitHub Pages and the repository

The files are hosted on GitHub Pages. GitHub processes the request that delivers the file, under GitHub's own terms. The source is in a public repository. Do not send secrets in an issue.

Contact

There is no contact form. A correction can be filed as a GitHub issue on anlap26/free-online-calculators. This policy was written on 19 November 2026.
