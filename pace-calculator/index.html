Pace calculator

Pace and speed from a distance and a time, or the missing one of those three when you already know the pace.

A mile is 1.609344 kilometres. The page uses that factor and does not read a watch.

Pace is per the distance unit selected above. In the distance mode it is per kilometre if you leave the unit on kilometres.

Pace is time divided by distance. Speed is distance divided by time. The page keeps both a kilometre and a mile, using 1.609344 kilometres in a mile, so a result in one unit is not a rounded cousin of the other. Ten kilometres in 50 minutes is 3,000 seconds. Divided by 10, that is 300 seconds per kilometre, which is 5:00. The same 10 kilometres is 10 / 1.609344 miles, and the pace per mile is 3,000 seconds divided by that distance. Speed is 10 kilometres in 50/60 of an hour, which is 12 kilometres per hour. Those are the checks.

The first mode wants a distance and a time in hours, minutes, and seconds. The second wants a distance and a pace in minutes and seconds, and it returns the time. The third wants a time and a pace, and it returns the distance. In the second and third modes the pace is per the distance unit selected in the distance fields when that unit is on the form. In the distance-from-time mode the pace is per kilometre if the unit stays on kilometres, which is what the note under the pace fields says. A pace of zero or a time of zero is rejected, because the division would be undefined. Negative times are rejected.

The three questions are the same relation

If 10 kilometres takes 50 minutes, the pace is 5:00 per kilometre. If the pace is 5:00 per kilometre and the distance is 10 kilometres, the time is 50 minutes, which is 3,000 seconds. If the time is 50 minutes and the pace is 5:00 per kilometre, the distance is 10 kilometres. Change the unit to miles and the same physical run is reported in miles and in minutes per mile, using the exact mile. A marathon distance is something you type. The page does not store 42.195 kilometres as a hidden default, so a race distance you care about has to be entered.

The calorie page does not know this pace, and this page does not know your weight, so it will not print a calorie burn. That would be a second model stacked on this one. BMI does not use time. Splits, hills, and stops inside the run are invisible: the page sees one distance and one elapsed time, or one pace held constant. A moving time and an elapsed time are different numbers. Type the one you mean.

What the arithmetic leaves out

  • No GPS track, no heart rate, and no grade.
  • A pace that changes along the way is averaged into the single pace the totals imply.
  • The mile factor is exact. A rounded 1.6 would not match.

Daily calories are on the calorie calculator. The index of weight and height is the BMI calculator. Other unit factors, including the mile itself, are on the unit converter.

Questions people ask

What is the pace of 10 kilometres in 50 minutes?

Five minutes per kilometre, and 12 kilometres per hour. The mile pace uses 1.609344 kilometres per mile.

Which field does each mode use?

Pace-from-distance uses distance and time. Time-from-pace uses distance and pace. Distance-from-pace uses time and pace. The unused fields are hidden.

Is a mile exactly 1.6 kilometres?

No. A mile is 1.609344 kilometres. The page uses that factor.

Does this estimate calories burned?

No. It does not ask for weight. Calories are a different page and a different equation.
