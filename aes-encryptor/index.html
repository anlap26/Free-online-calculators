Send the password on a different channel

The ciphertext is only as private as the place you paste it. If someone else needs the password, that message is a separate step. A private mailbox such as Proton can carry it. Plans change, and this page does not list every mail feature.

Proton Mail

The page encrypts text with AES-GCM. The key is a 256-bit key derived from the password with PBKDF2 and SHA-256, using 150,000 iterations, a random 16-byte salt, and a random 12-byte IV. Salt and IV both come from crypto.getRandomValues. The output you copy is base64. Decoded, the bytes start with a version marker, the four characters ENC1, then the salt, then the IV, then the ciphertext. One string carries the whole package, so the same password can open it later without a separate file for the salt. Nothing is uploaded. There is no account that could keep a recovery copy. The work happens in the browser, and closing the tab drops both the note and the password from this page.

A wrong password fails closed

GCM checks integrity. A wrong password or a flipped character fails the check, and the page returns no text. It does not hand back a partial note, and it does not try nearby passwords in case you were close. There is no recovery. If the password is lost, the text is gone. This site cannot help, because the password never left the browser and we do not hold a spare. Write the password into a manager before you close the tab. Make that key on the password generator, where the entropy is counted properly, and look at it on the strength checker if you typed it yourself. A short password undermines the 150,000 iterations. Those rounds slow a guess. They do not invent bits the password did not have.

The password has to travel separately

This is not a way to send a secret by email unless the password goes by a different channel. The ciphertext is only as private as the place you paste it. One email, one chat, or one ticket that contains both the base64 and the password has handed over both pieces. A shared document stays shared, even when the bytes look random. Someone who can open that document can copy the string and, if the password is there too, open the note. Keep your copy of the password in a manager. If another person must have the password, send it as its own message, not as a footnote under the ciphertext. A private mailbox is a modest way to carry that one message. Proton is a mailbox you can use for the exchange. Plans change. This page is not a catalogue of mail features, and it does not claim the ciphertext becomes safer because of a brand name on the button.

A hash of the note is not a substitute. Anyone can recompute a hash, and a hash does not hide the text. Stripping EXIF is about photos, not about this string. The password manager guide is where the comparison of storage tools lives. Put the password there, paste the ciphertext only where the people who should not read the note cannot also read the password, and assume that a backup of the base64 without the password is a backup of nothing you can open.

Questions people ask

Which algorithm is this?

AES-GCM with a 256-bit key. The key comes from PBKDF2 and SHA-256, 150,000 iterations, a random 16-byte salt, and a random 12-byte IV. The output is base64. The decoded bytes start with the version marker ENC1.

What if I forget the password?

There is no recovery. The password never left the browser, and this site has no copy. A lost password means the text is gone.

Why does one changed character fail?

GCM checks integrity. A wrong password or a damaged character fails the check, and the page returns no text. It does not guess or return a partial note.

Can I email the ciphertext on its own?

Only if the password travels on a different channel. The ciphertext is as private as the place you paste it. The same email as the password hands over both pieces.

How should I choose the password?

Use the password generator and store the result in a manager. The iteration count slows guessing. It does not add bits the password never had. A private mailbox such as Proton can carry the password to another person, separate from the ciphertext. Plans change.
